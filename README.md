# WebFlyx — Shell Practice Dataset

**Status:** learning exercise · scratch repo

A small dataset used while practising command-line file and text manipulation — a fictional
"WebFlyx" movie collection.

## Contents

```
titles.md      movie titles in the collection
classics.csv   comma-separated list of classic movies
quotes/        one file per movie, with memorable quotes
```

## What this is not

Not a product, not a library, and not maintained. It is kept only so the exercises stay
reproducible. If you were looking for real work, the rest of this account is the place.
